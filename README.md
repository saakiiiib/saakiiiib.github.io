# saakiiiib.github.io

Personal academic research portfolio and printable CV for **M. Nazmus Sakib**, hosted on GitHub Pages at <https://saakiiiib.github.io/>.

## Structure

- `index.html` — main research portfolio page
- `resume.html` — printable CV page
- `assets/css/` — stylesheets (`site.css`, `resume.css`)
- `assets/js/main.js` — canvas particle backdrop, reduced-motion controls, navigation, and scroll reveals
- `favicon.svg`, `og.png` — site icon and Open Graph preview card

## Preview locally

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.
